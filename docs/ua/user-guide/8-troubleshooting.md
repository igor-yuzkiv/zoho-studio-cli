# Розв'язання проблем

## Команда не знаходить проєкт

`No .zoho-studio/settings.json found` — ви поза папкою проєкту. Перейдіть у проєкт або створіть
його командою `zoho-studio init`.

## Вхід

| Що ви бачите | Що робити |
|---|---|
| `invalid_client` | Client id або secret не збігаються з клієнтом в API-консолі, або проєкт налаштовано на інший дата-центр — перевірте [дата-центри](3-zoho-connection.md#дата-центри). |
| `other_dc` | Ваш обліковий запис в іншому дата-центрі, ніж зазначено в налаштуваннях, — вкажіть обидві адреси для свого регіону. |
| `access_denied` | Доступ відхилено на екрані підтвердження — запустіть `zoho-studio login` знову й підтвердьте. |
| `The device code expired` | Код не ввели вчасно — запустіть `zoho-studio login` знову. |
| `This project is not authorized yet` | Запустіть `zoho-studio login` у цьому проєкті. |

Після переміщення чи перейменування папки проєкту увійдіть знову: збережений доступ прив'язано до
старого шляху.

## Завантаження

| Що ви бачите | Що робити |
|---|---|
| `OAUTH_SCOPE_MISMATCH` | Вхід у проєкт виконано ще до того, як з'явилася підтримка цього виду ресурсів. Запустіть `zoho-studio login` знову, щоб надати поточні дозволи. |
| `No modules found … Run "zoho-studio z-crm:modules:pull" first` | Поля завантажуються для завантажених модулів; спершу завантажте модулі. |
| Підсумок повідомляє про невдалі елементи (`… failed: 1`, `Failed: 1`) | Один елемент не вдалося завантажити; його назву й причину наведено під цим рядком. Решту збережено. |

## Браузер

Завантаження, запущене зі сторінки, відхиляється, поки виконується інше, — дочекайтеся, доки
перше завершиться. `--port` із портом, який уже зайнятий, завершується помилкою; не вказуйте цю
опцію, і застосунок візьме вільний порт.

## Міграції

| Що ви бачите | Що робити |
|---|---|
| `Cannot find package '@zoho-studio/zoho-crm'` | Пакети не встановлено в проєкті: один раз виконайте `bun run link` у репозиторії Zoho Studio, потім `bun install` у проєкті. |
| `Conflicts:` зі списком | Міграція не відповідає CRM — кожен рядок каже, що зайнято або чого бракує. Змініть файл і знову запустіть `--dry-run`. |
| `was already applied to this organization` | Вона вже запускалася тут. Для подальших змін напишіть нову міграцію. |
| `fields were not created` | Zoho відхилив деякі поля; рядки вище називають їх і причину. Виправте їх у новій міграції `update`. |

## Якщо нічого не допомогло

Кожна команда пише в `logs/zoho-studio-cli.log` у проєкті; наприкінці файлу зазвичай видно повну
помилку. Браузер показує той самий лог на сторінці огляду.
