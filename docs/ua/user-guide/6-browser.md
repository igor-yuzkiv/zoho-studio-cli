# Браузер

`zoho-studio browser` відкриває проєкт у вебзастосунку на вашому комп'ютері: ви бачите все
завантажене, згруповане за видами, і можете оновити будь-яку групу одним клацанням.

```bash
zoho-studio browser               # opens your default browser
zoho-studio browser --no-open     # only prints the address
```

Застосунок працює, доки ви не натиснете Ctrl+C у терміналі. Він доступний лише з вашого комп'ютера.

## Що в ньому можна робити

- **Переглядати** завантажені файли за групами — модулі, функції, робочі процеси та інше — і
  відкривати будь-який із них.
- **Завантажувати знову** будь-яку групу; сторінка показує перебіг і той самий підсумок, що й
  команда. Одночасно виконується лише одне завантаження.
- **Читати лог** кожної команди, від найновіших записів, унизу сторінки огляду.
- **Входити** з рядка стану, коли в проєкті ще не виконано вхід, так само, як через
  `zoho-studio login`.
