# Підключення до Zoho

Zoho Studio звертається до Zoho з вашого дозволу, який надається один раз для проєкту через
`zoho-studio login`. Для цього потрібен **клієнт** — запис, який ви реєструєте в API-консолі Zoho, —
і він зберігається на вашому комп'ютері як **профіль**, тож кілька проєктів можуть користуватися
тим самим клієнтом.

## Клієнт

1. Відкрийте [api-console.zoho.com](https://api-console.zoho.com) під обліковим записом, до CRM
   якого потрібен доступ, у дата-центрі, де цей обліковий запис зареєстровано.
2. Додайте клієнт типу **Non-browser Mobile Applications**. Цьому типу не потрібна адреса
   перенаправлення, тож нічого не має працювати на сервері.
3. Скопіюйте його `Client ID` і `Client Secret`, коли `login` їх попросить.

## Вхід

```bash
zoho-studio login                  # pick a profile or create one
zoho-studio login --profile acme   # use a stored profile directly
```

`login` показує посилання й код; відкрийте посилання в будь-якому браузері, введіть код і
підтвердьте. Код дійсний кілька хвилин. Після цього проєкт залишається з виконаним входом: CLI сам
поновлює доступ, і `login` знадобиться знову, лише якщо доступ відкликали в Zoho, клієнт замінили
або ви перемістили папку проєкту.

`zoho-studio z-crm:status` будь-коли підтверджує підключення, показуючи організацію.

На екрані підтвердження перелічено, що Zoho Studio просить дозволу робити. Цей перелік береться з
`auth.scopes` у налаштуваннях; типове значення охоплює все, що робить інструмент, зокрема
створення модулів і полів для міграцій.

## Дата-центри

Zoho має окремі дата-центри, і кожен обліковий запис належить до одного з них. Якщо ваша CRM
відкривається не на `zoho.com`, а на іншому домені, перед входом вкажіть обидві адреси в
`.zoho-studio/settings.json`:

```json
{
    "auth": { "baseUrl": "https://accounts.zoho.eu" },
    "api": { "baseUrl": "https://www.zohoapis.eu" }
}
```

Замість `.eu` підставте закінчення свого регіону — `.in`, `.com.au`, `.jp`, `.ca`, `.com.cn`.

## Де зберігаються облікові дані

Профілі й токени лежать у `~/.zoho-studio` у вашій домашній папці, ніколи не в проєкті, і читати
їх може лише ваш користувач. Ставтеся до цієї папки як до пароля: будь-хто, у кого вона є, може
читати вашу CRM.
