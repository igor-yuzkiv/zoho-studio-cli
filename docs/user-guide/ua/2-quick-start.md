# Швидкий старт

Ця інструкція проведе вас від встановленого CLI до проєкту, у який завантажено всю конфігурацію
CRM і який відкрито в браузері. Закладіть близько десяти хвилин, більшість із них — на одноразове
налаштування клієнта в Zoho.

## 1. Створіть проєкт

```bash
zoho-studio init my-crm
cd my-crm
```

Проєкт — це звичайна папка; `init` додає до неї файл налаштувань і ще кілька файлів. Що це за
файли, описано на сторінці [Проєкт](4-project.md).

**Якщо ваш обліковий запис Zoho не в дата-центрі США** (наприклад, він відкривається на `zoho.eu`),
вкажіть регіон одразу в `.zoho-studio/settings.json` — див. [Підключення до Zoho](3-zoho-connection.md#дата-центри).

## 2. Зареєструйте клієнт у Zoho — один раз

1. Відкрийте [api-console.zoho.com](https://api-console.zoho.com) під своїм обліковим записом CRM,
   у своєму дата-центрі.
2. Додайте клієнт типу **Non-browser Mobile Applications**.
3. Не закривайте сторінку: її `Client ID` і `Client Secret` знадобляться на наступному кроці.

Один клієнт обслуговує всі ваші проєкти.

## 3. Увійдіть

```bash
zoho-studio login
```

Виберіть **Create a new profile**, дайте профілю назву й вставте client id і secret. Потім CLI
покаже посилання й короткий код: відкрийте посилання, введіть код і надайте доступ. Термінал
підтвердить вхід і покаже, до якої організації ви підключені.

## 4. Завантажте все

```bash
zoho-studio preset pull-crm
```

Ця команда запускає всі завантаження одне за одним. Файли з'являться в `src/zoho-crm/`.

## 5. Подивіться

```bash
zoho-studio browser
```

У браузері відкриється вебзастосунок з усім, що ви завантажили. Зупинити його можна клавішами Ctrl+C.

## Що далі

- Додайте проєкт у git: `git init && git add . && git commit -m "CRM snapshot"`. Налаштування
  й секрети вже виключено з нього — див. [Проєкт](4-project.md#що-потрапляє-в-git).
- Запускайте `zoho-studio preset pull-crm` знову щоразу, коли потрібен свіжий знімок; `git diff`
  покаже, що змінилося в CRM.
