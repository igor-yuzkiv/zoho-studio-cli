# Change log

What each released version of zoho-studio — the CLI and its Claude Code plugin — changed and how to
update to it. One file per version: `v<version>.md`, matching the git tag `v<version>`.

## What goes here

- A version file, written during a release by the `/release` skill.

## What does not

- Changes that are not released yet.
- The current description of the tool — it lives in `docs/` and `README.md`.

Version files are not rewritten after the release. The one exception is a mechanical fix of relative links when a document they link to moves to another folder.
