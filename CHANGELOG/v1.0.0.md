# zoho-studio v1.0.0 — 2026-11-28

## Summary

The first versioned release: it records what zoho-studio could do when versioning was introduced. Earlier work has no versions, so this release has no list of changes — it describes the tool as it stood.

## What zoho-studio does

zoho-studio is a CLI that keeps Zoho CRM resources as local files, so Zoho development fits normal engineering workflows: git, an editor, code review.

### Project and connection

- `init` creates a project: settings in `.zoho-studio/`, folders for pulled data and sources, migrations, widgets, scripts, and a `.gitignore`.
- `login` connects the project to a Zoho CRM organization through OAuth; credentials and tokens are kept in `~/.zoho-studio` under named profiles.
- `z-crm:status` and `z-crm:org:info` show the connection and the organization.
- `preset` runs a named sequence of commands from the presets in the project settings.
- `browser` serves a local web app to browse pulled artifacts, run pulls, log in, and test widgets.

### Pulling metadata

Pull commands save Zoho CRM metadata as JSON under `data/`: modules, fields, layouts, workflow rules, workflow actions, webhooks, global picklists, profiles, client scripts, static resources, and functions.

### Functions

`z-crm:functions:pull`, `make`, `import`, `deploy`, and `run` keep Deluge functions as `.deluge` files: pull them, start a new one, bring a pulled one into sources, deploy it after a confirmation, and run it in the organization.

### Migrations

`z-crm:migrations:make` starts a migration file, and `bun run migrate` in a project creates modules and adds fields from the files in `migrations/zoho-crm/`: it plans the run against the organization, asks before applying, verifies the result, and journals the run.

### Widgets

`z-crm:widgets:make` starts a widget, and `z-crm:widgets:serve` runs widgets in an emulated Zoho CRM page with mocked SDK calls; projects get a widget testing skill for Claude Code.

### Scripts

Projects can import the framework packages (`@zoho-studio/core`, `@zoho-studio/zoho-crm`) in their own scripts.

## How to install

Clone the repository, then `bun install`, `bun run compile`, put `dist/zoho-studio` on your `PATH`, and run `bun run link` once — see the README.
