# zoho-studio v1.0.1 — 2026-11-28

## Summary

The CLI now reports its version, and the repository gets versioned releases. Nothing changes in how existing commands behave; no action is needed after updating.

## Changes

### Added

- `zoho-studio --version` (or `-V`) prints the version of the CLI.
- Versioned releases: one version for the repository, a tag `v<version>` per release, and a change log per version in `CHANGELOG/`.

## How to update

Pull the repository and run `bun run compile` again; check the result with `zoho-studio --version`.
