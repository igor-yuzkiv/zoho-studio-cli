# zoho-studio v1.1.0 — 2026-11-28

## Summary

This version makes the CLI ready for AI agents and safer to pull with: `zoho-studio instructions` tells an agent what the CLI does and how to work with it, `bun run setup` installs and updates the CLI in one step, and a pull no longer erases what Zoho deleted — it moves it to `data/.removed/`. After updating, run `bun run setup` once; in an existing project, add `data/.removed/` to `.gitignore`.

## Changes

### Added

- `zoho-studio instructions [name]` — instructions for AI agents, built into the executable: the project, where to start, which commands write to Zoho, and what the CLI does not do; a group (`z-crm`, `z-crm:functions`) or one command by name. The groups carry guides: reading the pulled files and how they refer to each other, working with functions, writing and running migrations, testing widgets with scenarios and mocks.
- `bun run setup` — installs the CLI from the clone or updates it after `git pull`: builds the executable, links it as `~/.local/bin/zoho-studio`, registers the packages for project scripts, and prints the installed version. macOS and Linux.
- `zoho-studio init` makes the new project a git repository (`git init`, no commit), unless the folder is already inside one.

### Changed

- A pull no longer deletes and rewrites its folder. Files whose content did not change stay as they are; files for what Zoho no longer has move to `data/.removed/<date-time>/` under the same path. An item whose details failed to download keeps its file from the previous pull.
- A pull in which some items failed now exits with code 1, so scripts and presets see the failure.
- `z-crm:functions:deploy` that hits an existing function with the same API name suggests pulling and importing it with `z-crm:functions:import`.
- The documentation is regrouped into guides and a reference by command group, in English and Ukrainian, and checked against the code.

## How to update

```bash
git pull
bun run setup
```

The first `bun run setup` may stop if `~/.local/bin/zoho-studio` is already something else — for example, a link you made by hand to another place. Run `bun run setup --force` to replace it, or `--bin-dir <path>` to install elsewhere. In a project created before this version, add `data/.removed/` to its `.gitignore`.
