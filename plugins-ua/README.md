# plugins-ua

Український переклад `plugins/` — щоб кожну інструкцію плагіна можна було вичитати українською. Структура й імена файлів повторюють `plugins/`; правила — `.claude/rules/translation.md`.

## Що сюди кладемо

- Переклад кожного скіла, промпту та інструкції з `plugins/` за тим самим відносним шляхом.

## Що сюди не кладемо

- Нічого, чого немає в `plugins/`. Джерело правди — `plugins/`; Claude Code завантажує лише `plugins/`, ця папка в прод не йде.
