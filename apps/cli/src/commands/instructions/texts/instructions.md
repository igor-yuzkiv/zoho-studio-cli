# instructions

Prints these instructions: without a name — the project and every command; with a group
(`z-crm`, `z-crm:functions`) — that group and its commands; with a command — that command.

- **Writes to Zoho:** no. **Needs login:** no. **Needs a project:** no.

## When to use

Before using a command for the first time, and when unsure whether the CLI can do something at all
— the overview lists what it does not do. Options stay in `zoho-studio <command> --help`.
