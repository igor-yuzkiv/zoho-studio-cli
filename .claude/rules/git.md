# Git

- Agents may commit completed, verified work without asking.
- Commit messages in English, conventional-commits style: `feat:`, `fix:`, `refactor:`,
  `chore:`, `docs:`, `test:`.
- Do NOT add AI attribution to commits: no "Generated with Claude Code", no
  `Co-Authored-By: Claude` trailers, no tool mentions in the message body.
- One logical change per commit. Do not mix refactoring with behavior changes.
- Never commit `.env`, tokens, or anything from `.zoho-studio/` local config.
- Do not push, rebase, or amend published history without an explicit request.
